# 招投标材料智能编制与核验平台

第二个独立项目，与「提水工程项目」分开存放。

规划见 [项目规划书.md](./项目规划书.md)。本地测试版对应阶段 1：建项目、导入文件、规则抽取要求矩阵、人工确认。不调用外部模型。

```text
pip install -r backend/requirements.txt
python -m uvicorn backend.app.main:app --reload
```

浏览器打开 http://127.0.0.1:8000 ，可用 `samples/脱敏招标文件样例.txt` 试导入。工作目录请设为仓库根目录。

依据文档：[招投标材料智能编制与核验平台项目需求(1).md](./招投标材料智能编制与核验平台项目需求(1).md)（2026-10）。
